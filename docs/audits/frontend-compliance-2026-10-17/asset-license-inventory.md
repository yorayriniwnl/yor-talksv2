## Follow-up fixes that remove avoidable dependencies

All **87** original Unsplash literals across 13 pages and two Steam demo components were removed. Static demo portraits now use the existing initial-avatar fallback; demo covers use six local geometric variants. No genuine community discussion, product photograph or user avatar was changed. A dead commented community fixture was removed while its API-backed mapper remains unchanged.

The eight fixed GIFs were in `GifPickerModal`, which the active composer imports but never mounts; its visible GIF control already says attachments are unavailable. The dormant gallery now has an empty unavailable state with the same component/props/type contract. Static image upload behavior is preserved.

The dormant, unimported `TerminalInsanity` component no longer contains remote MP3 playback or associated cleanup. Its remaining generated effects were preserved and were not enabled. **Two unreferenced still-life files were removed from the public directory**, preventing **2,580,728 bytes** of uncleared, unused image distribution. Original paths/hashes are in the removal evidence.

The source rescan covers all HTTP(S) literals and protocol-relative renderer/source strings, including GIF/GIPHY/Tenor/Picsum/placeholder/CDN forms. No hardcoded external image or music URL remains under `social/src`. XML namespace identifiers, explicit auth/payment scripts and example form URLs are distinguished from fetchable media. CSP host allowlists were retained so this cleanup does not change permitted dynamic user-media behavior.
