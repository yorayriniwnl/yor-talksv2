This audits the workspace lockfile, including frontend build packages, because build dependencies can enter shipped artifacts. It does not prove that packages have no undisclosed vulnerabilities. [Machine-readable result](evidence/dependency-audit-pnpm11.json).

An earlier run with the preinstalled pnpm 9 CLI reported a different dependency count and is superseded by the pinned pnpm 11 result. No dependency was upgraded merely because a newer version exists. The local generated validation package `@workspace/api-zod` is declared and referenced by the TypeScript project but is currently not imported by server source; it remains part of separate contract generation/validation and can be reviewed for declaration cleanup. `@types/web-push` is declared in runtime dependencies although it is type-only; these are packaging cleanup items, not confirmed security defects.

The current server dependency inventory records **27 declarations**, including two local workspace packages. [Declared ranges and resolved versions](evidence/backend-dependencies.json). Principal resolved versions are Express 5.2.1, Drizzle 0.45.2, PostgreSQL driver 8.23.0, Socket.IO 4.8.3, Redis adapter 8.3.0, ioredis 5.11.1, BullMQ 5.80.9, bcryptjs 2.4.3, jsonwebtoken 9.0.3, multer 2.4.0, otplib 12.0.1, Pino 9.14.0, pino-http 10.5.0 and Zod 3.25.76. ## Licenses and contracts

The pinned CLI produced **652 package records** from installed workspace importers, including development and optional packages. Absolute machine paths were removed from the evidence. [License inventory](evidence/dependency-licenses.json).

Three records have `Unknown` package metadata: the frontend Replit cartographer/dev-banner plugins and the backend transitive package `thirty-two@1.0.2`. Manual inspection of `thirty-two/LICENSE.txt` found an MIT permission notice; its metadata remains reported honestly as `Unknown`. The two Replit plugins remain a frontend/operator review item. `web-push` carries MPL-2.0; `lightningcss`/its native package also carry MPL-2.0; `caniuse-lite` carries CC-BY-4.0. Distribution notices, applicable source obligations, provider DPAs and commercial acceptance require owner review. The inventory is not legal approval, and it does not prove which development packages enter a browser bundle.
